# Контрольная работа №1 — Учебный интернет-магазин

## Описание
Многостраничный HTML/CSS-сайт учебного интернет-магазина по дисциплине
«Фронтенд и бэкенд разработка».

## Тема контрольной работы №1
«HTML и CSS: разработка многостраничного сайта».

## Ссылка на опубликованный проект
GitHub Pages: https://sokkaza.github.io/kr1-html-css-shop/

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара;
- `order.html` — оформление заявки;
- `contacts.html` — контакты и FAQ;
- `css/style.css` — стили проекта;
- `js/main.js` — скрипт модального окна и формы;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список исключений Git.

## Используемые технологии
- HTML5;
- CSS3;
- JavaScript;
- Git;
- GitHub;
- GitHub Pages.

## БЭМ-структура проекта
- `site-header`, `site-nav`, `site-footer`;
- `hero`, `section`, `advantages`, `info-block`;
- `products-grid`, `product-card`, `product-detail`;
- `catalog-layout`, `catalog-filters`, `catalog-products`;
- `breadcrumbs`;
- `order-dialog`, `order-form`;
- `product-table`;
- `reviews`, `faq`;
- `button`, `success-message`, `to-top`.

## Использование Flexbox и Grid
- Flexbox — навигация, карточки, кнопки;
- CSS Grid — сетка товаров, каталог, карточка товара, отзывы.

## Позиционирование
- `position: sticky` — шапка сайта, фильтры каталога;
- `position: fixed` — кнопка «Наверх»;
- `position: relative` — карточки товаров;
- `position: absolute` — бейджи «Скидка», «Новинка», «Хит»;
- `z-index` — модальное окно, шапка, кнопка «Наверх».

## Как проверить проект
1. Открыть `index.html` — проверить hero-блок, преимущества, карточки товаров.
2. Открыть `catalog.html` — проверить фильтры, сетку из 6 товаров, бейджи.
3. Открыть `product.html` — проверить карточку товара и таблицу характеристик.
4. Открыть `order.html` — проверить форму заявки.
5. Открыть `contacts.html` — проверить контакты и FAQ.
6. Нажать «Заказать» на главной — открыть модальное окно, заполнить форму.

## Самостоятельные доработки
- Фиксированная кнопка «Наверх»;
- sticky-фильтр каталога;
- 6 товаров в каталоге вместо 3;
- БЭМ-модификаторы карточек (`--discount`, `--featured`);
- бейджи «Скидка», «Новинка», «Хит»;
- блок отзывов на странице товара;
- блок FAQ на странице контактов;
- улучшенное модальное окно с анимацией;
- дополнительные состояния кнопок (`:active`);
- улучшенная доступность формы (`aria-describedby`).
